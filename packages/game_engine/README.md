# game_engine

Motor del juego Clash of Words: reglas del Clash, Items, Effects, pilas y fin de partida.

Está escrito en Dart puro y no depende de Flutter, de la interfaz ni del almacenamiento (RNF-09), para que pueda probarse por sí solo y reutilizarse en otras plataformas.

## Ejecutar los tests

```bash
cd packages/game_engine
dart test
```
